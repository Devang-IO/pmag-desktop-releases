# PMAG Desktop

Official Windows installers and the public update feed for PMAG. Application source is maintained privately.

Download the installer from [Releases](https://github.com/Devang-IO/pmag-desktop-releases/releases/latest). Install once, then use **Settings → App & Updates**.

Existing 0.1.x users must install the rebuilt 0.2.0 app once to switch update feeds. The app connects to the same PMAG service and account.

The current installer is unsigned and Windows may display an unknown publisher warning. Only download installers from this repository.
